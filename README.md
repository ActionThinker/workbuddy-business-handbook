# WorkBuddy 生意手册（WorkBuddy Business Handbook）

> **用 WorkBuddy 赚钱，从超级个体开始** —— 免费开源手册：7 级赚钱阶梯 · 三卷 How-to · 零公司可起步
> 社区共创版 · 非 WorkBuddy 官方文档 | 站点：https://handbook.workbuddylink.com（DNS 配置中）

写给**没有公司、没有资质、但想借 WorkBuddy 生态做点小生意**的个人与小微团队（超级个体 / OPC）的实战手册。纵轴对齐 WorkBuddy 官方「超级个体 → 超级团队 → 超级组织」，横轴是 L0–L6 七级赚钱阶梯：每级标清赚什么钱、落脚点、投入、收益、能否立马做。

## 站点结构

| 路由 | 内容 |
|------|------|
| `/` | 首页：阶梯速览 + 双模块入口 + 人才池入口 |
| `/ladder` | 赚钱阶梯：9 赚钱模式 + 11 落脚点 + L0–L6 表 |
| `/guide` | 变现路径指南：5 路径 A–E + 7 天启动包 |
| `/modules` | 章节模块：三卷 13 章 + 脊柱速查表 |
| `/paid` | 付费专区：P1–P4 四档（人工成交） |
| `/talent` | 人才池登记（免费） |
| `/about` | 非官方声明 + 运营方 + 许可 + 十年/三年/一年想法 |
| `/assets` | 资产模板库（陆续开放） |
| `/ladder-map.html` | 赚钱阶梯可视化大图（独立页面） |
| `/path-map.html` | 路径地图可视化大图（独立页面） |
