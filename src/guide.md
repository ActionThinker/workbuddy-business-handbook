# 路径指南：没公司也能开始的 5 条路

> 这一章先给你结论：这份手册写给谁、现在做可不可行；再给你 5 条路径、第一步、成本和周期，和一个 7 天启动包。
> 社区共创版，非 WorkBuddy 官方文档；文中官方机制以各官方页面最新说明为准。

## 0. 先给你结论

**你不需要先开公司，也不需要官方资质，就能用 WorkBuddy 赚钱。**

三条低门槛事实：

- `open.workbuddy.cn` **开放平台个人可入驻**，造 Skill / 专家 / 应用直接上架；
- 做内容、做推荐（官方邀请计划，邀请好友得 Credits 积分）**不需要任何主体**；
- 想做培训/咨询也**不必自己养交付团队**——WorkBuddyLink 渠道伙伴"有客户资源即可申请，FDE 后端统一交付"。

真正阻碍你的不是资质，是"不知道从哪条路先迈脚"。下面给 5 条路 + 一个 7 天启动包。

### 为什么可行（三个硬支撑）

1. **需求真实** —— 大量个体"看好产品但不懂变现"，方法论稀缺；
2. **路径已就位** —— 5 条路径全部映射到 WorkBuddy 真实生态机制（见下表）；
3. **零公司可起步** —— 开放平台个人可入驻、内容/推荐无需主体、渠道伙伴可合作。

| 你想做的事 | 对应的真实机制 | 是否需要公司 |
|---|---|---|
| 岗位经验做成资产包 | `open.workbuddy.cn` 开放平台 | **个人可入驻** |
| 做内容 / 推荐 | 官方邀请计划（得 Credits 积分） | **无需主体** |
| 考证后培训 | 官方认证（如 OPC 从业者认证，以官方最新政策为准） | 个人可考 |
| 咨询 / FDE 交付 | WorkBuddyLink 渠道伙伴 | 可合作 |
| 团队无公司做业务 | 渠道伙伴（有资源即可，FDE 后端交付） | 可合作 |

⚠️ **两个必须注意的点**：

- **品牌合规**：本书是"非官方社区版"，不宣称官方授权或代理关系；
- **内容时效**：产品迭代快，需社区维护、按大版本更新。

## 2. 五条路径详解

### 路径 A 资产上架（Skill / 模板 / 应用）

- **适合谁**：任何有岗位或行业经验的人
- **第一步**：去 `open.workbuddy.cn` 注册个人开发者 → 把你最常用的一个工作流封装成 1 个 Skill 或模板
- **成本**：几乎为零（时间为主）
- **收入**：开源免费引流 + 付费定制/订阅 + 上架分成
- **周期**：1–2 周出第一个资产
- **官方已实践**：WorkBuddy「收入变现」已上线——技能/专家可自主定价售卖（一次性买断 / 按月订阅，内测期平台服务费 1%）。详见 [赚钱阶梯](/ladder) 的「官方实践信号」。

### 路径 B 内容 + 推荐

- **适合谁**：爱分享、有账号运营习惯的人
- **第一步**：起一个 WorkBuddy 实战账号（视频号/小红书/公众号），周更 2 篇；挂官方邀请链接（以官方最新说明为准）
- **行动**：[点此拿官方邀请链接](https://www.workbuddy.cn/events/invite?inviteCode=xh7ekcwz3m5s4tr)（好友注册与付费，双方都可得 Credits 积分）
- **成本**：零
- **收入**：广告 + 社群 + 邀请积分（推荐奖励为 Credits 积分，需叠加其他路径变现）
- **周期**：1 个月起有稳定流量

### 路径 C 考证 + 培训

- **适合谁**：有讲课能力或行业背书的人
- **第一步**：从腾讯官方认证四部曲选一级报考增加个人背书——[OPC 从业者](https://cloud.tencent.com/edu/cert/developer/1056)（入门）→ [应用师 CEA](https://cloud.tencent.com/edu/training/cert/detail?type=CEA)（进阶）→ [CodeBuddy 架构师 CCB](https://cloud.tencent.com/edu/training/cert/detail?type=CCB)（专家）→ [FDE](https://cloud.tencent.com/edu/training/cert/detail?type=CFD)（交付）→ 打磨一门"AI 办公提效"课
- **成本**：低（考试+时间）
- **收入**：企业内训、公开课、训练营
- **周期**：2–4 周拿证，即可接课
- **官方已实践**：2026-10-24 腾讯 FDE 精英班在北京/深圳/成都开班（官方公众号），FDE 认证可独立报考；官方还将逐步开放讲师、助教体系
- **为什么要考证**：不是为了当"官方代表"，而是**增加个人背书**——有认证的讲师，企业更愿意信任与下单。考证路径以官方最新政策为准。

### 路径 D 渠道伙伴 / 接单

- **适合谁**：有客户资源的人（伙伴） / 能交付的人（接单）
- **第一步（伙伴）**：在 WorkBuddyLink 申请渠道伙伴，专注获客，FDE 后端交付
- **第一步（接单）**：在接单平台挂"WorkBuddy 实施/培训"服务，先接小单练手
- **成本**：低
- **收入**：返佣（持续）/ 按单收费
- **周期**：伙伴需跑通 1 个试点再放大；接单 1 周内可开张
- **官方已实践**：FDE（前沿部署工程师）= 扎根业务一线做 AI 落地的角色。考 FDE 认证后，以 WorkBuddy 为基座承接企业落地交付项目（精英班培养体系：「线下集训—90 天陪伴—能力认证」）。

### 路径 E 超级个体：专家孵化 + 陪跑（重点）

- **适合谁**：想把自己变成"资产"的人——你的专长可以被 WorkBuddy 用户随时召唤
- **第一步**：在开放平台把你的领域经验封装成**专家智能体（Expert）**，同时开**小班陪跑**带其他想入门的人
- **成本**：低
- **收入**：专家被调用分成 + 陪跑/教练费 + 内容（三重叠加）
- **周期**：2–3 周成型
- **官方已实践**：「收入变现」已支持**付费专家**上架——把你自己封装成可售卖的专家，按月订阅或一次性买断。
- **为什么是终局**：超级个体 = 你的知识被资产化、24 小时可被调用、还能教别人复制——这是"用 WorkBuddy 赚钱"的最高杠杆形态。

## 4. 常见问题（你最担心的）

**Q1：没公司能收钱吗？**
能。前期用平台托管交易（接单平台/内容平台）或个人对私合规收款；赚到钱再注册**个体工商户**（线上极简）。开放平台个人入驻、内容/推荐都无需主体。

**Q2：要交税吗？**
要，但个体户税率低、有起征点。详见"合规财税"模块；原则是：**先小规模合规，再扩大**。

**Q3：多久能赚到第一笔？**
接单/内容最快 1–2 周（小单）；资产上架/培训 2–4 周；渠道伙伴需先跑通 1 个试点。

**Q4：会被封号/违规吗？**
不碰"官方代理/认证"的虚假承诺、不刷量、遵守平台协议即可。定位清晰："陪跑/咨询/资产"，不做未授权的官方背书。

**Q5：和官方关系是？**
本书是社区版。想做正规伙伴走 WorkBuddyLink 渠道伙伴；想上架资产走开放平台。两者都不要求你先有公司。
