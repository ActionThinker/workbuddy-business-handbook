# 关于本站

## 这是什么

《WorkBuddy 生意手册》是一份**社区共创的实战手册与入口站**：面向没公司、没资质、想借 WorkBuddy 生态赚钱的个人与小微团队（超级个体 / OPC），提供从 0 到 1 的路径、方法与网络。

- **免费开源版**：7 级赚钱阶梯、5 条路径指南、三卷模块全景——看懂就能动手；
- **付费专区**：进阶手册、私享社群、1v1 陪跑、行业方案——带你跑通第一笔；
- **人才池**：登记进入生态协同网络——被看见、被连接、被派单。

本站是 WorkBuddyLink 的第三条受众线：企业客户、渠道伙伴之外的**个体线**。

## 我们的想法（看十年，想三年，干一年）

- **看十年**：AI 个体经济成熟，"超级个体"成为主流就业形态之一。谁的生态里有一张"能交付的个体网络"，谁就是供给侧枢纽——我们希望成为 WorkBuddy 个体生态的**默认入口与人才网络**：想做 WorkBuddy 生意的人，第一站来这里。我们不做平台、不扩团队，只做**入口与网络**。
- **想三年**：人才池分层运营形成规模；本手册成为该领域的内容资产；付费专区跑通 SOP；人才池与渠道伙伴体系互认——成为渠道伙伴的交付供给方。
- **干一年**：把免费内容做扎实、把人才池首批人聚起来、把付费模式验证掉。一年后看两个硬指标：**人才池规模**与**付费验证**——不达标就收缩为"内容资产 + 轻运营"，不追加投入。
