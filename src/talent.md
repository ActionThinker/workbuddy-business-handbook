# 人才池：进入生态协同网络

> 最重要的事是聚合一群人才。没有人才池，就没有交付能力——渠道大生意（L5）与生态价值供应链（L6）都建立在"有一群能交付 / 能教 / 能开发的人"之上。

## 1. 人才池是什么

人才池 = 借 WorkBuddy 生态赚钱的**个体集合**：能交付的、能教的、能开发的。它是站点的核心资产，也是未来对接渠道伙伴需求、企业落地需求的**供给侧**。

**一句话**：把"想用 WorkBuddy 赚钱的人"，变成"能被派单、能被合作、能互相成就的人才网络"。

## 2. 为什么它最重要

| 层级 | 缺了人才池会怎样 |
|---|---|
| 流量中枢（引流/转化） | 有流量无供给，转化后交付不了 |
| 渠道大生意（L5） | 有客户无交付团队，接不住 |
| 生态价值供应链（L6） | 无枢纽节点，供应链断裂 |

人才池是**上游供给**，其他层是下游需求。先聚人，才有后续一切。

## 3. 人才分层（对齐赚钱阶梯）

| 人才等级 | 对应阶梯 | 可贡献 |
|---|---|---|
| 萌新 | L0–L1 | 学习者、案例见证 |
| 资产客 | L2–L3 | 能上架 Skill/做内容/陪跑 |
| 交付者 | L4 | 能培训/咨询/FDE |
| 渠道/枢纽 | L5–L6 | 能获客/整合/做区域行业枢纽 |

## 4. 轻量运营：免费加入，先交流、再共创

我们不把它做成一个"平台"，只做**一个持续交流的圈子**：

- **免费加入**：登记即进，不设门槛、不收费；
- **先给甜头**：加入后你**先得到**——官方动态速递（收入变现、FDE 认证等一手信号）、考证路径答疑、模板与案例先享；
- **再邀请贡献**：分享你的实战案例、回答别人的问题、一起完善手册内容——贡献者会获得署名，以及更多被推荐参与项目 / 合作的机会；
- **不承诺、不画饼**：现阶段我们**不承诺**派单、收入或任何官方身份。先让大家讨论交流起来，一起把社群内容和手册越做越好。

**一句话**：先认识彼此，一起把路走通——派单与合作是水到渠成的事，不是承诺。
