# 赚钱阶梯：L0–L6 七级体系

> 本页先**钉死两件事**：赚钱模式（钱从哪来）、赚钱落脚点（你能卖的具体东西）；再给出**七级成长阶梯**（投入 / 收益 / 能力 / 能否立马做 / 对应超级阶段）；最后对齐 WorkBuddy 官方"超级个体 → 超级团队 → 超级组织"定义。
> 设计目标：**你一眼看出哪些能立刻做起来。**

## 0. 与官方对齐（为什么这么分）

WorkBuddy 官方把用户成长定义为 **超级个体 → 超级团队 → 超级组织**（个人出发、团队出发、组织/企业出发，每个阶段都有不同的服务支撑）。本体系完全沿用这条纵轴，并在其下挂"七级赚钱阶梯"作为横轴，让每个人按自己的阶段取用、逐级升级。

> 文中涉及的官方机制（开放平台、渠道伙伴、推荐计划、认证体系等）以各官方页面最新说明为准。

| 等级 | 名称 | 赚什么钱 | 落脚点 | 投入要求 | 月收入(参考) | 需要能力 | 立马可做 | 超级阶段 |
|---|---|---|---|---|---|---|---|---|
| **L0** | 自用觉醒 | 省下的时间/效率（间接） | 自己用 WorkBuddy 提效 | 几小时~几天学习 | ¥0（省时） | 会用基础功能 | ✅ **立刻** | 超级个体 |
| **L1** | 资产沉淀 | 未来变现的原材料 | 岗位经验→Skill/模板/知识库 | 你的经验（零成本，数天） | ¥0（积累） | 归纳/封装 | ✅ **立刻** | 超级个体 |
| **L2** | 资产变现 | M1 销售分成 + 付费定制 | 开放平台上架 Skill/模板/应用 | 封装时间（1–2 周），**个人可入驻** | ¥500–5,000 起，可被动 | 能做资产 | ✅ **立刻** | 超级个体 |
| **L3** | 内容+陪跑 | M8 引流 + M5 陪跑 + M7 推荐 | 内容账号 + 小班陪跑 | 表达+时间（零成本，持续） | ¥3,000–15,000 | 表达/带人 | ✅ **立刻** | 超级个体 |

### 立刻可做的四件事（给你的第一眼答案）

- **L0 自己用** → 今天就能提效
- **L1 沉淀资产** → 把你最熟的活封装成 Skill
- **L2 上架变现** → 开放平台个人入驻，零公司
- **L3 内容+陪跑** → 起账号、免费带 3 个人攒案例

> 一句话：**L0–L3 全部零公司、零资质、今天就能动手；L4 考官方认证（2–4 周）增加个人背书后就能接课；L5 有资源就能申请渠道；L6 是终局生态生意。**

### 官方实践信号（2026-10 · 两条实证）

**信号一 · 收入变现（L2 资产上架）**

WorkBuddy 已上线**「收入变现」**：个人开发者可以把技能 / 专家上架**自主定价售卖**（公开报道《WorkBuddy 悄悄上线「收入变现」，可自主定价技能和专家》· 公众号「产品笔记」，[原文链接](https://mp.weixin.qq.com/s/ccFgtw2mWbzibMojX1sBxw)）。

- **付费方式**：一次性买断 / 按月订阅（平台已有付费技能、专家上线）；
- **个人可发布**：专家、技能、连接器（Buddy 应用需企业开发者角色）；
- **零代码**：让 WorkBuddy 把你常用的任务直接转成技能/专家，导出 zip 包上传即可；
- **开通收款条件**：完成开发者认证 + 无违规记录 + ≥1 个审核通过的技能/专家；
- **费用**：内测期平台服务费 1%；官方示例定价 79 元一次性买断。

→ **L2 资产变现的路径已经真实打开**：先做出第一个资产，审核通过就能开卖。内测期政策以官方最新说明为准。

**信号二 · FDE 精英班与认证（L4 考证背书）**

2026-10-24，腾讯 WorkBuddy FDE 精英班在北京、深圳、成都三城同步开班——**全国首个由 AI 产品原厂牵头**的 FDE 人才培养与认证体系（腾讯云开发者社区联合 WorkBuddy 客户成功团队推出；来源：腾讯WorkBuddy 官方公众号，[原文链接](https://mp.weixin.qq.com/s/aQGcJ1P3GMUPbYlYHkCV5Q)）。

- 培养体系：「线下集训 — 90 天陪伴 — 能力认证」三位一体；
- **腾讯云 FDE 认证面向所有人开放，可独立报考**——考证路径真实存在；
- 首期 280 名学员来自 105 家企业、15 个行业，七成以上每天使用 WorkBuddy；
- 11–12 月将扩至上海、重庆、杭州、广州、东莞、苏州等城市；2027 年计划 200 场教学、培养 1 万名 FDE；
- 官方将**逐步开放讲师、助教体系**——会教别人的人，本身也是生态机会。

→ **L4 考证背书路径已被官方打开**：考 FDE 认证 → 积累 FDE 案例增加背书 → 把 WorkBuddy 当基座承接交付项目；再往后，官方讲师/助教开放时还能站上讲台。

### 考证的价值（L4 特别说明）

考证不是为了冒充"官方代表"，而是**增加个人背书**：有认证的讲师与顾问，企业客户更愿意信任、更容易下单。考证路径已明确可走：**腾讯云 FDE 认证**（面向所有人开放、可独立报考）、OPC 从业者认证等，均以官方最新政策为准；拿到认证后，再用交付案例持续加固背书。

## 4. 三级跃迁地图（超级个体 → 超级团队 → 超级组织）

```
超级个体 (L0–L4)
  自己用好 → 沉淀知识资产 → 上架变现 → 内容陪跑 → 培训咨询
        │  支点：个人能力 + 开放平台 + 内容
        ▼
超级团队 (L4–L5)
  培训/咨询规模化 → 申请渠道伙伴 → 招小队分包交付
        │  支点：客户资源 + FDE 后端交付 + 团队管理
        ▼
超级组织 (L5–L6)
  整合专家/技能/交付 → 做区域/行业枢纽 → 生态价值供应链
          支点：生态经营 + 价值网络
```

- **个体小生意** = L2–L4（一个人也能跑通）
- **渠道大生意** = L5（持续返佣 + 团队）
- **生态商业价值网络** = L6（供应链式价值分配）

## 5. 怎么用这本 How-to 系列（按阶段取用）

- **还在犹豫的人** → 读 L0–L1，先自己用起来
- **想马上赚第一笔** → 直奔 L2–L3，照"7 天启动包"做
- **有行业背书想放大** → L4 考证增加个人背书 + 培训咨询
- **有资源想做渠道** → L5 渠道伙伴
- **想建生态生意** → L6，先做前面积累
