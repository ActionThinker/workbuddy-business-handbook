# 第4章 L2 资产变现：开放平台上架 ★

> 结论先行：官方「收入变现」已上线——个人可以把技能 / 专家上架自主定价售卖。这是 L2 的正式通道：把第3章的资产，变成真金白银。
> 社区共创版，非 WorkBuddy 官方文档；文中官方机制以各官方页面最新说明为准。

## 1. 官方信号（已实证）

WorkBuddy 已上线**「收入变现」**：个人开发者可上架付费技能 / 专家（一次性买断 / 按月订阅）。公开报道与细节见 [赚钱阶梯](/ladder) 的「官方实践信号」：

- **个人可发布**：专家、技能、连接器（Buddy 应用需企业开发者角色）；
- **零代码**：把常用任务直接转成技能/专家，导出 zip 包上传；
- **上架变现门槛**：完成开发者认证 + 无违规记录 + ≥1 个审核通过的技能/专家；
- **费用**：内测期平台服务费 1%（以官方最新说明为准）。

## 2. 上架全流程（六步）

1. **个人入驻**：`open.workbuddy.cn` 注册个人开发者，完成认证；
2. **封装资产**：把第3章沉淀的资产做成 Skill / 模板 / 专家；
3. **导出上传**：导出 zip 包上传（零代码路径）；
4. **等待审核**：官方审核通过后获得上架资格；
5. **定价上架**：设一次性买断或按月订阅价格；
6. **持续迭代**：按用户反馈更新版本，好评滚雪球。

## 3. 变现策略：开源引流 + 付费分层 + 上架分成

| 层 | 内容 | 作用 |
|---|---|---|
| 免费引流款 | 基础版 Skill / 模板 / 内容 | 让用户认识你、试用你 |
| 付费完整款 | 进阶版资产（定价上架） | 真正收费的部分 |
| 定制服务 | 按需定制 / 陪跑 / 实施 | 高客单的延伸 |

> 逻辑：**免费层拿流量与信任，付费层拿收入**。只上架不引流，等于开店没人路过。

## 4. 定价参考（非承诺）

- 官方示例：**79 元一次性买断**（内测期公开报道示例，以官方最新说明为准）；
- 建议从「免费款 + 付费完整款」起步，先跑通一个资产再谈规模化；
- 收入因人而异、因资产而异——L2 参考区间见 [赚钱阶梯](/ladder)。

## 5. 适不适合你

- ✅ 适合：已经有 1 个成型资产（第3章完成）的人
- ⏳ 前置条件：开发者认证 + 至少 1 个审核通过的技能/专家——没有资产别硬上架

## 6. 第一步清单

- [ ] 完成开放平台个人入驻与开发者认证
- [ ] 上传第 1 个资产，走完一次审核全流程
- [ ] 定免费引流款 + 付费完整款的价格
- [ ] 把资产链接发到你的社群 / 账号，跑第一波用户

## 7. 案例（示例）

一位有政务窗口工作经验的人，把「群众办事材料预审」整理成检查清单 Skill：免费版公开引流，付费版加了 8 类高频事项的预审口径。上架后从免费用户里转出第一批付费定制需求——**免费层养活付费层**。

## 8. 避坑

- ❌ 不验证需求就封装：上架没人买，先拿免费款试水
- ❌ 定价脱离价值：79 元能买到完整解决方案很值，但 790 元的空壳没人要
- ❌ 只上架不引流：把第6章的内容账号开起来，流量是上架的氧气

## 9. 模板：资产包结构设计 + LICENSE 选择

**资产包目录（示例）**：

```
my-skill/
├── README.md        # 一句话说清解决什么问题 + 怎么用
├── skill/           # 资产本体（zip 包）
├── examples/        # 3 个使用示例
└── LICENSE          # 开源协议
```

**LICENSE 选择**：

| 协议 | 特点 | 适合 |
|---|---|---|
| MIT | 宽松，商用友好 | 想快速传播的免费款 |
| CC BY-NC 4.0 | 署名 + 非商用 | 引流款（本书同款） |
| 私有授权 | 不公开源码 | 付费完整款 |
