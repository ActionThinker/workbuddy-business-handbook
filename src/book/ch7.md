# 第7章 L4 培训 + 咨询：考证背书后放大 ★

> 结论先行：考证不是为了当「官方代表」，而是增加个人背书——有认证的讲师与顾问，企业客户更愿意信任、更容易下单。背书上身，接课、接咨询、接 FDE 项目。
> 社区共创版，非 WorkBuddy 官方文档；文中官方机制以各官方页面最新说明为准。

## 1. 认证四部曲（腾讯官方认证，个人可考）

| 认证 | 级别 | 适合谁 | 官方入口 |
|---|---|---|---|
| **OPC 从业者认证** | 入门 | 一人公司 / 效率达人 | [报名](https://cloud.tencent.com/edu/cert/developer/1056) |
| **应用师认证（CEA）** | 进阶 | 职场人士 / 企业构建者 | [报名](https://cloud.tencent.com/edu/training/cert/detail?type=CEA) |
| **CodeBuddy 架构师（CCB）** | 专家 | 开发者 / 架构师 | [报名](https://cloud.tencent.com/edu/training/cert/detail?type=CCB) |
| **FDE 前沿部署工程师** | 交付 | 扎根业务一线做 AI 落地 | [报名](https://cloud.tencent.com/edu/training/cert/detail?type=CFD) |

> 2026-10-24 腾讯 FDE 精英班在北京、深圳、成都开班（官方公众号），FDE 认证**可独立报考**；官方还将逐步开放讲师、助教体系。考证政策以官方最新说明为准。

**选法**：讲 AI 办公提效 → OPC/CEA；做企业落地交付 → FDE；技术集成 → CCB。**考一级就够启动，不用攒全套。**

## 2. 打磨一门「AI 办公提效」课

五模块骨架（可直接套用）：

1. 认知：AI 现在能干到什么程度（30 分钟）
2. 实操：3 个高频场景现场做（90 分钟）
3. 方法：怎么把 AI 用进自己的工作流（30 分钟）
4. 演练：学员带自己的活来练（60 分钟）
5. 复盘：成果展示 + 后续陪伴计划（30 分钟）

> 课程目标锚定「学员当场完成一个自己的提效场景」——这比讲 100 页 PPT 都管用。

## 3. 企业内训 SOP（五步）

1. **接触**：从免费分享 / 公开课切入，展示实战案例；
2. **诊断**：访谈 3–5 个岗位，找到最痛的重复劳动；
3. **定制**：课程案例全部换成对方行业的真实场景；
4. **交付**：半天 / 一天训练营，现场带练 + 课后作业；
5. **复盘**：回收成果清单，形成案例（征得同意后展示）。

## 4. 咨询与 FDE 项目怎么报价（参考，非承诺）

- **报价三要素**：范围（做什么）、周期（多久）、交付物（交什么）——三者任一变，价格就要变；
- **建议结构**：基础服务费 + 定制费 + 差旅，分开列；
- **参考区间**：企业内训与咨询按天 / 按项目计，区间见 [赚钱阶梯](/ladder) L4 行；先从小单做起，案例多了再提价。

## 5. 适不适合你

- ✅ 适合：有讲课 / 行业经验、愿意考证背书的人；想接企业客户的人
- ⏳ 前置：先拿一个认证（2–4 周）+ 至少 1 个公开课 / 内训案例

## 6. 第一步清单

- [ ] 从四部曲选一级报名（建议先 OPC 或 FDE）
- [ ] 用五模块骨架打磨自己的第一门课
- [ ] 办 1 场免费公开课 / 免费分享，录屏当案例
- [ ] 跑通 1 单企业内训（哪怕小单），沉淀前后对比案例

## 7. 案例（示例）

一位有 8 年政务信息化经验的从业者，考下 FDE 认证后，用「AI 公文提效」公开课切入本地政务场景，两周内接到第一场内训邀约——**认证背书 + 行业经验 + 实战案例**三件套，是企业下单的关键。

## 8. 避坑

- ❌ 无背书硬接大单：先小单练手，别让第一个企业客户变成最后一个
- ❌ 冒充官方讲师：明确「个人讲师 / 持证讲师」身份，不做官方背书
- ❌ 低价内卷：报价守住三要素底线，靠案例提价不靠砍价

## 9. 模板：课程大纲 + 培训报价单 + FDE 交付 SOP

**课程大纲（骨架）**：课程名 / 一句话价值 / 目标学员 / 时长 / 五模块内容 / 学员产出。

**培训报价单（要点）**：

| 项 | 内容 |
|---|---|
| 课程 | 《AI 办公提效实战》半天 |
| 范围 | 30 人以内，1 个场地 |
| 交付物 | 课程 + 学员成果清单 + 课后问答（2 周内） |
| 价格 | 基础价 + 定制费 + 差旅（分开列） |

**FDE 交付 SOP（五步）**：需求访谈 → 方案确认（范围/周期/交付物）→ 部署实施 → 验收培训 → 持续陪跑（90 天）。
