# 第3章 L1 资产沉淀：把岗位经验变原料 ★

> 结论先行：你干了多年的岗位经验，就是最值钱的原材料。沉淀的要点不是「写文档」，而是「把方法变成别人能复用的东西」。
> 社区共创版，非 WorkBuddy 官方文档；文中官方机制以各官方页面最新说明为准。

## 1. 什么值得沉淀：三个标准

| 标准 | 问自己 | 例子 |
|---|---|---|
| 高频 | 这件事每周都发生吗？ | 周报、对账、巡检、标书 |
| 有方法 | 有「步骤」可拆吗？ | 五步做标书、三步做纪要 |
| 可复用 | 换个人也能照做吗？ | 换个同事也能上手 |

**三条都中 → 值得沉淀；中两条 → 先记录，后沉淀；只中一条 → 跳过。**

## 2. 沉淀成什么：四种形态

| 形态 | 是什么 | 适合什么经验 |
|---|---|---|
| **模板** | 填空即用的结构 | 文档类（报告/纪要/通知） |
| **Skill** | 封装好的任务能力 | 流程类（整理/拆解/生成） |
| **知识库** | 成体系的知识集合 | 专业类（政策/规范/案例） |
| **专家（Expert）** | 你的经验化身 | 问答类（咨询/判断/口径） |

> 新手建议顺序：**模板 → Skill → 知识库 → 专家**，由易到难。
> 五卡体系（把专家经验拆成卡片的提取方法，WorkBuddy 技能市场可找到）是做这一步的现成工具。

## 3. 适不适合你

- ✅ 适合：有 1 年以上岗位经验的人；带过新人的人（你早就总结过方法）
- ⏳ 不适合：经验还没成型的人——先去第2章用起来

## 4. 第一步清单

- [ ] 从你的岗位挑 1 件「高频 + 有方法 + 可复用」的事
- [ ] 把这件事写成 5–8 个步骤（口头能讲清，就能写出来）
- [ ] 挑一种形态（建议模板或 Skill）做出第一版
- [ ] 找 1 个同事试用，按反馈改一版

## 5. 案例（示例）

一位金融行业做合规材料的员工，把「监管材料自查」整理成一份 6 步清单 + 检查模板。同事试用后反馈「照着做省一半时间」——这份原料后来封装成 Skill，成为第4章上架的第一个资产。

## 6. 避坑

- ❌ 沉淀「自嗨内容」：你觉得有价值、别人用不上——对照三标准自查
- ❌ 只存文档不封装：文档躺在文件夹里不会变成资产
- ❌ 一步到位心态：第一版粗糙很正常，先有再改
