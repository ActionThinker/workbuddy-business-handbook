# 第1章 认知：WorkBuddy 能力地图 ★

> 结论先行：赚钱的本质是「你帮谁解决了什么问题」。WorkBuddy 是一套能力积木，先认清每块积木能干什么，你才知道自己能卖什么。
> 社区共创版，非 WorkBuddy 官方文档；文中官方机制以各官方页面最新说明为准。

## 1. 能力积木：七件套一览

| 积木 | 是什么 | 一句话理解 |
|---|---|---|
| **Skill 技能** | 把一类任务封装成可复用能力 | 你的「拿手活」打包 |
| **Expert 专家** | 你领域经验的智能体化身 | 你的「分身顾问」 |
| **连接器** | 打通 WorkBuddy 与外部工具/系统 | 让数据与流程流动 |
| **Buddy 应用** | 打包完整场景的解决方案 | 你的「场景产品」 |
| **模板工作流** | 预设好的流程模板 | 别人的好方法拿来即用 |
| **Explore / 发现** | 技能与专家的市场入口 | 发现并调用别人的资产 |
| **硬件** | 与 WorkBuddy 联动的实体设备 | 把智能体接到现实 |

> 个人起步，先吃透 **Skill、Expert、模板工作流** 三块——它们就是第3–5章的主战场。

## 2. 赚钱本质：你帮谁解决什么问题

| 买方 | 他们的问题 | 你能卖什么 |
|---|---|---|
| 个人 | 「我不会用 / 没时间」 | 模板、陪跑、小课 |
| 团队 | 「协作乱 / 重复劳动多」 | Skill、定制工作流 |
| 部门 | 「流程卡 / 数据散」 | 应用、咨询服务 |
| 企业 | 「怎么落地 / 谁能交付」 | 培训、FDE 交付项目 |

**先选一层买方，再定你的资产**——不要对着空想「做个什么」，要对着人问「谁有什么问题」。

## 3. 适不适合你

- ✅ 适合：任何有岗位或行业经验的人；想用 AI 提效的人；想找副业方向的人
- ⏳ 需要补的：没有具体岗位经验的人，先到第2章用起来，再回来

## 4. 第一步清单

- [ ] 注册 WorkBuddy，跑通一个官方模板工作流
- [ ] 在 Explore / 发现 里装 1 个 Skill，用它解决一件小事
- [ ] 列出你工作中最重复的 3 个任务（写下来，后面要用）
- [ ] 想清楚：你最常被同事 / 朋友问的是什么问题？（这往往是你的机会点）

## 5. 案例（示例）

一位做工程标书的岗位员工，每天最重复的事是把招标文件拆成要点。他先用模板工作流提速，再把「招标文件要点拆解」封装成 Skill 思路——这就是从认知到资产的完整路径：**先自己用，再封装，再给别人用**。

## 6. 避坑

- ❌ 不先认清积木就冲去「做个产品」——大概率做出没人要的东西
- ❌ 把 WorkBuddy 当成万能——它解决「用 AI 干活」，不解决「你没有经验」
- ❌ 只逛不练——认知来自动手，不来自收藏

## 7. 模板：机会画布（痛点—方案—收费）

| 画布格子 | 填什么 | 示例 |
|---|---|---|
| 买方 | 谁会为这件事付费 | 中小企业行政岗 |
| 痛点 | 他们最烦什么 | 周报 / 会议纪要每天占 1 小时 |
| 方案 | 你用 WorkBuddy 给什么 | 一个「纪要+周报」模板工作流 |
| 收费 | 怎么定价（参考，非承诺） | 模板免费引流，定制版收费 |
| 验证 | 先找谁验证 | 先免费帮 3 个人用，听反馈 |

> 这张画布填得出来，你的生意就有雏形；填不出来，回到第2章先自己用。
