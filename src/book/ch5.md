# 第5章 专家孵化：把自己变成可被召唤的专家 ★

> 结论先行：Expert 是超级个体的最高杠杆形态——你的经验被封装成智能体，24 小时可被调用，还能卖钱。官方「收入变现」已支持付费专家上架。
> 社区共创版，非 WorkBuddy 官方文档；文中官方机制以各官方页面最新说明为准。

## 1. Expert 是什么

Expert（专家智能体）= 你领域经验的化身：用户遇到问题，召唤「你」来解答。它与 Skill 的区别：

| | Skill | Expert |
|---|---|---|
| 解决 | 一类任务 | 一类问题 |
| 形态 | 工具 | 顾问 |
| 例子 | 「把会议录音转纪要」 | 「政务材料怎么准备」 |
| 变现 | 买断 / 订阅 | 调用分成 + 订阅 + 陪跑 |

> Skill 卖「活」，Expert 卖「你」——经验越深、越难被复制的人，越适合做 Expert。

## 2. 三步封装

1. **定边界**：只回答你最熟的领域，边界外明确说不（例如「我专注工程投标，不回答其他行业」）；
2. **建知识结构**：把你脑子里的经验写成问答对 / 流程 / 口径（第3章的知识库就是底料）；
3. **定对话口径**：给 Expert 设定语气、立场、免责边界——它代表你的专业形象。

## 3. 三重收入叠加（参考，非承诺）

- **调用分成**：Expert 被使用，你按平台规则分成；
- **订阅 / 买断**：付费专家上架（官方「收入变现」已支持）；
- **陪跑 / 咨询**：Expert 是获客入口——用过的人找你做 1v1、小班（详见 [第6章](/book/ch6)）。

## 4. 适不适合你

- ✅ 适合：有 3 年以上专业经验、常被人请教的人；想做高客单服务的人
- ⏳ 不适合：经验还在积累期的人——先走第3、4章

## 5. 第一步清单

- [ ] 写下你「最常被问的 10 个问题」及标准答案
- [ ] 划定 Expert 的领域边界（能答什么、不答什么）
- [ ] 在开放平台创建 Expert，填入知识结构
- [ ] 用 5 个真实问题测试它，按回答质量改口径

## 6. 案例（示例）

一位做过多年制造业采购的人，把「供应商评估怎么问、怎么看」封装成采购顾问 Expert。用户免费试用后，追着他开小班讲「采购避坑 20 条」——Expert 引流，陪跑变现。

## 7. 避坑

- ❌ 范围过宽：「什么都懂」的专家 = 什么都不精
- ❌ 冒充官方：明确标注「个人经验分享」，不做官方背书
- ❌ 知识不更新：Expert 里的内容过时 = 砸自己的专业招牌

## 8. 模板：专家人设卡

| 卡片项 | 填什么 | 示例 |
|---|---|---|
| 一句话定位 | 你是谁、帮谁解决什么 | 帮中小企业行政把材料一次过审 |
| 擅长领域 | 3 个以内 | 公文写作 / 材料预审 / 流程梳理 |
| 边界声明 | 不答什么 | 不提供法律意见 |
| 典型提问 | 用户会怎么问你 | 「这个报告结构对吗？」 |
| 交付口径 | 你的回答风格 | 先结论、再步骤、给模板 |
