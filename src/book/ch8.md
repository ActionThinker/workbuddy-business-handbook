# 第8章 合规安心：个人视角的三条底线 ★

> 结论先行：小生意合规不难，就三条底线——身份边界、数据保密、合同先行。守住它们，生意做得久。
> 社区共创版，非 WorkBuddy 官方文档；文中官方机制以各官方页面最新说明为准。

## 1. 底线一：身份边界（你是谁，说清楚）

- **非官方声明**：你不是 WorkBuddy 官方，也不自称官方；培训、内容、资产都标注「个人出品」；
- **不做官方背书**：不承诺「官方代理 / 包过 / 官方指定」；
- **渠道身份**：想长期做企业业务，走 WorkBuddyLink 渠道伙伴，以资源伙伴身份协同合作（详见 [赚钱阶梯](/ladder) L5）；
- **案例展示**：展示客户案例前征得同意，隐去敏感信息——信任比炫耀重要。

## 2. 底线二：数据与保密（尤其政府/企业客户）

- **最小化收集**：只拿完成任务必需的数据，不顺手带走；
- **存储授权**：客户数据只存客户允许的地方；
- **交付后清理**：项目结束按约定清理本地数据；
- **保密条款**：服务合同里写清保密义务（模板见下）。

## 3. 底线三：合同先行（开工前签）

关键条款至少四条：

1. **范围**：做什么、不做什么（防止无限加需求）；
2. **交付物**：交什么、什么标准算完成；
3. **验收**：客户怎么确认、多久内反馈；
4. **变更**：需求变了怎么算（改价 / 改期）。

> 电子合同同样有效；先小人后君子，合同是保护双方，不是不信任。

## 4. 适不适合你

- ✅ 必读：所有开始接活 / 上架 / 开小班的人——哪怕第一单只有几百块
- ⏳ 提醒：合规不是「等做大再说」，第一条底线从第一天就要有

## 5. 第一步清单

- [ ] 检查你的账号 / 内容 / 资产是否有「官方」暗示，全部改为「个人出品」
- [ ] 准备一份标准服务合同模板（要点见下）
- [ ] 处理客户数据前，确认存储与清理方式
- [ ] 展示任何案例前，征得客户同意并脱敏

## 6. 避坑

- ❌ 为了接单夸大身份：一句「官方合作」可能砸掉整个口碑
- ❌ 客户数据随便存：丢了数据 = 丢了生意
- ❌ 无合同开工：口头约定最怕「需求变了」

## 7. 模板：标准服务合同 + 保密条款 + 报价单（要点）

**标准服务合同（要点）**：双方信息 / 服务范围 / 交付物与标准 / 周期 / 验收方式 / 变更处理 / 保密条款 / 争议解决。

**保密条款（要点）**：保密范围（客户数据与商业信息）/ 保密期限 / 违约后果 / 数据清理约定。

**报价单（要点）**：服务项 / 单价 / 数量 / 合计 / 有效期 / 备注（范围外另议）。
