# 模块全景：三卷 How-to（全书骨架）

> 本手册以 **[赚钱阶梯](/ladder)** 为脊柱：纵轴对齐 WorkBuddy 官方"超级个体 → 超级团队 → 超级组织"，横轴是 **L0–L6 七级赚钱阶梯**。
> 每章遵循"结论先行 → 适不适合你 → 第一步清单 → 案例 → 避坑 → 模板"的结构；标 ★ 为"零公司、零资质可立即起步"。

## 总纲 · 赚钱阶梯体系（必读）

- 赚钱模式（钱从哪来 · 9 种）与赚钱落脚点（你能卖的具体东西 · 11 类）
- 七级阶梯总表（投入 / 收益 / 能力 / 能否立马做 / 对应超级阶段）
- 三级跃迁地图（个体小生意 → 渠道大生意 → 生态价值供应链）
- **模板**：读者自测表（你现在是 L 几、该从哪级起步）

## 卷一 · 超级个体（L0–L4 · 个人出发）

### 第 1 章 认知：WorkBuddy 能力地图 ★

- 能力积木：Skill / Expert / 连接器 / Buddy 应用 / 模板工作流 / Explore / 硬件
- 赚钱本质 = 你帮谁解决什么问题；买方四层
- **模板**：机会画布（痛点—方案—收费）

### 第 2 章 L0 自用觉醒：先让自己提效 ★

- 用 WorkBuddy 解决自己的生活/工作痛点
- 为什么"自己先用好"是赚钱的地基
- **模板**：个人提效清单

### 第 3 章 L1 资产沉淀：把岗位经验变原料 ★

- 从你的岗位出发，沉淀知识资产（Skill/知识库/最佳实践）
- 五卡体系提取专家经验
- **模板**：知识资产提取清单

### 第 4 章 L2 资产变现：开放平台上架 ★

- 在 `open.workbuddy.cn` 个人入驻，上架 Skill / 模板 / 应用
- 开源引流 + 付费分层 + 上架分成（官方「收入变现」已上线：付费技能/专家自主定价，见 [赚钱阶梯](/ladder) 官方实践信号）
- **模板**：资产包结构设计、开源 LICENSE 选择

### 第 5 章 专家孵化：把自己变成 WorkBuddy 里的专家（超级个体核心）★

- Expert 是什么、为什么是超级个体的载体
- 把领域经验封装成"可被召唤的专家"
- 专家分成 + 陪跑 + 内容三重叠加
- **模板**：专家人设卡

### 第 6 章 L3 内容 + 陪跑：带人赚钱 ★

- 内容账号引流（视频号/小红书/公众号）+ 小班陪跑
- 挂官方邀请链接（得 Credits 积分），从流量到付费（以官方最新说明为准）
- **模板**：内容日历、陪跑 SOP、招募话术

### 第 7 章 L4 培训 + 咨询：考证背书后放大 ★

- 考证路径：腾讯官方认证四部曲——**OPC 从业者**（入门）/ **应用师 CEA**（进阶）/ **CodeBuddy 架构师 CCB**（专家）/ **FDE 前沿部署工程师**（交付）；考证 = 熟悉产品与交付方法 + 积累个人背书（详见 [赚钱阶梯](/ladder) 考证四部曲表）
- 打磨一门"AI 办公提效"课 + 企业内训 SOP
- 付费咨询 / FDE 项目怎么报价
- **模板**：课程大纲、培训报价单、FDE 交付 SOP

### 第 8 章 合规安心（安心模块 · 个人视角）★

- 电子合同、数据与保密（尤其政府/企业客户）
- **模板**：标准服务合同、保密条款、报价单

## 卷二 · 超级团队（L4–L5 · 团队出发）

### 第 9 章 从个体到团队：何时招人、如何分包 ★

- 副业 → 小生意 → 小队的演进信号
- 用 FDE 网络分包交付，不养重团队
- 多路径组合与收入对冲
- **模板**：收入结构表、分包检查表

### 第 10 章 L5 渠道伙伴：返佣 + 一起做业务 ★

- WorkBuddyLink 渠道伙伴机制（有资源即可，FDE 后端交付）
- 官方邀请计划（得 Credits 积分）；收益测算（以官方最新说明为准）
- **模板**：渠道试点计划、返佣测算表

### 第 11 章 区域 / 本地服务商：二三线城市打法 ★

- 政府/企业本地触点（区域资源即壁垒）
- 本地获客 + 后端交付协作
- **模板**：区域拓展清单

## 卷三 · 超级组织（L5–L6 · 组织/企业出发）

### 第 12 章 生态价值供应链：做区域/行业枢纽

- 整合专家 / 技能 / 交付，形成价值网络
- 上游供给 + 下游交付 + 平台分润的供应链式经营
- **模板**：生态合作地图

### 第 13 章 组织落地：不同发展阶段的不同服务支撑

- 大企业：私有化、定制、持续运营
- 与 L6 生态枢纽的衔接
- **模板**：企业落地选型表
